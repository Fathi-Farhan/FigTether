# README visuals

`architecture.svg` and `benchmark-stages.svg` are original FigTether illustrations, licensed under
the repository's MIT OR Apache-2.0 license. They contain no external resources or executable code.
They are not copied from Harness² or Figma.

Regenerate them with `node scripts/render-readme-assets.mjs`; use `--check` to detect drift.
The chart's reviewed source data and measurement limitations are in
[`benchmarks/published/`](../benchmarks/published/README.md). Keep the generated SVGs tracked so
GitHub can display them without a build step.
