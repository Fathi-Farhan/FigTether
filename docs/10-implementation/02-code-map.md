# Requirement to Code Map

Status: `Proposed`

This table connects every functional requirement of `FigTether_PRD_Confluence_v1.1` to the code
that implements it and to the test that proves it. It is the companion of
`docs/06-testing/03-traceability-matrix.md`: that document maps requirements to acceptance tests,
this one maps them to files.

Reading rule: a row is only honest when the "verified by" column names a test that exists and runs
today. Rows that still need a Figma Desktop session say so in the same column, because the PRD
forbids presenting planned behaviour as shipped behaviour.

## 2. Nonfunctional targets

| N   | Target                                           | Where it is engineered                                                            | Where it is measured                                     |
| --- | ------------------------------------------------ | --------------------------------------------------------------------------------- | -------------------------------------------------------- |
| N01 | Cached reads under 100 ms p95                    | `crates/core/src/cache.rs` (LRU with byte budget)                                 | `crates/bench` workload W1                               |
| N02 | Fresh reads under 2 s p95                        | `crates/core/src/scheduler.rs` (one op per session, queue with aging)             | `crates/bench` workload W2                               |
| N03 | PNG export under 5 s p95                         | `crates/core/src/assets.rs`, global export lane                                   | Needs a real editor: not measured                        |
| N04 | Idle RSS under 50 MiB, peak under 256 MiB        | `crates/core/src/limits.rs` (cache and asset budgets)                             | `crates/bench` workload W4 samples the resident set size |
| N05 | No crash, unexpected errors under 0.1 percent    | `crates/core/src/metrics.rs` counters                                             | `crates/bench` workload W4                               |
| N06 | No editor freeze longer than 1 s                 | Sliced traversal in `plugins/figma/main` (8 ms slices)                            | Needs a real editor: not measured                        |
| N07 | Cancel or revoke effective within 1 s            | `crates/core/src/scheduler.rs` (`cancel_session`), `crates/daemon/src/control.rs` | AT15                                                     |
| N08 | Offline within 15 s, reconnect ready within 10 s | `crates/daemon/src/bridge.rs` (heartbeat every 5 s, offline after 3 misses)       | AT09                                                     |
| N09 | No official MCP or REST request from the core    | The workspace contains no such client                                             | AT01, AT02                                               |
| N10 | First onboarding p90 under 15 minutes            | `figtether doctor`, `figtether pair`, `figtether config print`                    | Needs the G2 pilot with at least 10 users                |

## 3. How to verify a row

```sh
cargo test --workspace                       # the whole implementation
cargo test -p figtether-e2e --test acceptance # the acceptance flows
cargo run -p figtether-model --example export_schemas  # the published contract
npm --prefix plugins/figma test               # the plugin side
```

Every command above runs offline. No command in this repository contacts Figma, and no test
depends on a network path other than loopback.
