1. Connect your bridge
Where do I get the pairing secret?
  1. On this computer, open a terminal and run figtether. Leave it running.
  2. Open a second terminal and run figtether pair.
  3. Copy the secret printed there, paste it below, and press Pair.

Command not found? Build FigTether first and add its binary to your terminal's PATH. The secret comes from your local CLI, not Figma or your AI provider.

Update the Figma plugin import

  1. Close FigTether Bridge.
  2. Choose Plugins → Development → Import plugin from manifest….
  3. Select the file below. Its name must be exactly manifest.json.
  4. Open Bridge again, run figtether pair, and paste the new secret.

If Figma still opens the old import, remove that entry from Development → Manage plugins, then import this file again. Keep your source files.
